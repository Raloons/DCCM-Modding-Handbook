# Dead Cells Modding Handbook

## About This Project

**Dead Cells Modding Handbook** is a free, open-source community resource dedicated to helping developers learn how to create and expand mods for *Dead Cells* using the **Dead Cells Core Modding (DCCM)** framework.

The goal of this project is to make Dead Cells modding more accessible by providing clear explanations, practical tutorials, code examples, and technical references for both beginners and experienced developers.

While existing modding resources cover many fundamentals, more advanced topics can be difficult to learn without extensive experimentation. This handbook aims to bridge that gap by documenting techniques, common challenges, and development workflows in an organized, approachable format.

## What Does It Cover?

- **Getting Started:** Installing DCCM, setting up a development environment, and creating your first mod.
- **Custom Equipment:** Creating weapons, skills, mutations, projectiles, and equipment effects.
- **Animations and Visual Effects:** Working with animation sequences, sprite resources, custom effects, and rendering.
- **Gameplay Modifications:** Understanding damage scaling, combat behavior, movement, and interactions with native game systems.
- **Custom Levels and Biomes:** Creating rooms, working with level generation, implementing environmental artwork, and developing custom locations.
- **Game Data and Resources:** Working with CastleDB, resource packages, native data structures, and mod registration.
- **Debugging and Testing:** Diagnosing crashes, resolving compatibility issues, and safely testing modifications.

Tutorials include explanations and independently created examples wherever practical. Some advanced subjects may remain experimental or require additional verification.

## Requirements

This handbook focuses on modding through **Dead Cells Core Modding (DCCM)**.

DCCM and its associated development tools are required for following the implementation tutorials.

- [Dead Cells Core Modding - GitHub](https://github.com/dead-cells-core-modding/core)
- [DCCM Documentation](https://dead-cells-core-modding.github.io/docs/)

Requirements and compatibility may vary depending on the framework version and the tutorial. The reference game version for the initial tutorials is Dead Cells version 35.

## Project Philosophy

**Accessibility:** Technical information should be understandable without requiring extensive prior experience with Dead Cells' internal systems.

**Practicality:** Tutorials should explain not only what to do, but also why particular methods work and how to investigate problems when they don't.

**Collaboration:** Modding becomes easier when developers share knowledge, document discoveries, and build upon publicly available tools.

The project is intended to grow over time as techniques are documented, tested, and improved.
