# DCCM-Modding-Guides

This is a community resource created to helping developers learn how to create and expand mods for Dead Cells using the Dead Cells Core Modding (DCCM) framework. The goal of this project is to make Dead Cells modding more accessible by providing clear explanations and references for developers (and some AI assistants!).

While existing modding resources cover many fundamentals, more advanced topics can be difficult to learn without extensive experimentation. This handbook aims to bridge that gap by documenting techniques, common challenges, and development workflows in an organized, approachable format.

Tutorials are intended to include explanations and independently created examples wherever practical. Some advanced subjects may remain experimental or require additional verification.

## Requirements

This handbook focuses on modding through **Dead Cells Core Modding (DCCM)**.

DCCM and its associated development tools are required for following the implementation tutorials.

- [Dead Cells Core Modding - GitHub](https://github.com/dead-cells-core-modding/core)
- [DCCM Documentation](https://dead-cells-core-modding.github.io/docs/)

Requirements and compatibility may vary depending on the framework version and the tutorial. The version of Dead Cells used is version 35 (The End Is Near).
